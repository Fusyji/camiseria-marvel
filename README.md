# Camisería Marvel

Sitio web oficial y catálogo interactivo de **Camisería Marvel**, especializado en camisas artesanales, lino italiano de Biella, algodón egipcio Giza 87 y confección a medida (Bespoke / Su Misura).

## Características

- **Catálogo de Confección**: Colecciones filtrables por categoría (Lino Italiano, Formal & Negocios, Smart Casual, Ceremonia), tejido y tipo de cuello.
- **Detalle de Prenda**: Vista de especificaciones con procedencia de fibras, tipo de puños, botones de nácar natural y canal de consulta directa por WhatsApp.
- **Configurador A Medida (Bespoke)**: Herramienta interactiva para diseñar camisas paso a paso (tejido, color, cuello, puño, calce, monograma bordado y medidas personalizadas).
- **Guía de Tejidos y Cuidados**: Consejos para la conservación y características técnicas de cada material textil.
- **Canal de Citas y Atelier**: Formulario de reserva para toma de medidas y contacto directo con el taller.

## Ejecución

```bash
# Desarrollo
npm run dev

# Construcción de producción
npm run build

# Verificación de tipos
npm run lint
```
